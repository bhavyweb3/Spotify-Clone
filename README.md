# 🎵 SPOTIFY-CLONE

A modern **Spotify Clone** built to recreate the core music-streaming experience of Spotify. The project focuses on a clean user interface, music browsing, playlists, album/artist sections, and an interactive music player.

> 🎧 **SPOTIFY-CLONE — Bringing the music streaming experience to the web.**

---

## 📌 Features

* 🎵 Browse songs and music collections
* ▶️ Play and pause songs
* ⏭️ Next and previous track controls
* 🔊 Volume control
* 📊 Music progress/seek bar
* 💿 Album and playlist sections
* 🎤 Artist and song information
* 🔍 Search functionality
* 📱 Responsive user interface
* 🎨 Spotify-inspired dark theme
* ⚡ Smooth and interactive UI

---

## 🛠️ Technologies Used

* **HTML5** — Structure of the application
* **CSS3** — Styling and responsive design
* **JavaScript** — Functionality and music-player interactions

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone  https://bhavyweb3.github.io/Spotify-Clone/
```

### 2. Navigate to the project directory

```bash
cd SPOTIFY-CLONE
```

### 3. Open the project

If it is a simple HTML/CSS/JavaScript project, open:

```text
index.html
```

in your browser.

For a better development experience, you can use the **Live Server** extension in VS Code.

## 🎧 How to Use

1. Open the application.
2. Browse available songs, albums, or playlists.
3. Select a song.
4. Use the player controls to:

   * ▶️ Play
   * ⏸️ Pause
   * ⏭️ Skip to the next song
   * ⏮️ Return to the previous song
   * 🔊 Adjust volume
   * 📊 Change the playback position
5. Explore different sections of the application.
